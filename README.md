# مرشد TryHackMe بالعربي — الإصدارات

هذا المستودع للتوزيع فقط: ملف الإضافة وملف التحديث. الشيفرة في مستودع منفصل.

**نزّل:** [`thm-arabic-tutor-latest.xpi`](thm-arabic-tutor-latest.xpi)

---

## التثبيت الدائم مع تحديث تلقائي

الإضافة المؤقّتة (`Load Temporary Add-on`) تنمسح مع كل إغلاق لفايرفوكس ولا
تقدر تحدّث نفسها. للتثبيت الدائم:

**١)** `about:config` ← اقبل التحذير ← ابحث عن `xpinstall.signatures.required`
← اضغط عليه ليصير **false**

> يعمل على **Firefox ESR** (الافتراضي في Kali) وعلى Developer Edition. في
> فايرفوكس العادي الإعداد مُهمَل. تحقّق من `about:support` ← سطر Version.
>
> وتعطيله يسمح بتثبيت أي إضافة غير موقّعة، فلا تثبّت إلا ما تثق بمصدره.

**٢)** `about:addons` ← أيقونة الترس ⚙ ← **Install Add-on From File…** ←
اختر ملف `.xpi` المنزَّل

**٣)** خلاص. تبقى بعد إعادة التشغيل، وفايرفوكس يفحص التحديثات وحده.

## تحديث فوري

`about:addons` ← الترس ⚙ ← **Check for Updates**

## بعد التثبيت

`about:addons` ← الإضافة ← **Preferences**:

| الحقل | القيمة |
|---|---|
| المزوّد | Google Gemini (باقة مجانية) |
| مفتاح الـ API | من [aistudio.google.com/apikey](https://aistudio.google.com/apikey) — مجاني بلا بطاقة |
| اسم النموذج | اضغط **«اجلب المتاح»** واختر من القائمة |

ثم بالترتيب: **امنح الإذن للنطاق** ← **اختبار الاتصال** ← **حفظ الإعدادات**.

## وش تسوّي الإضافة

- **ترجم واشرح**: حدّد نصًّا في TryHackMe (أو اضغط `Alt+T`) فتجيك الترجمة
  والشرح بالعامية والمعنى التقني والمصطلحات
- **تشريح الأمر**: كل أمر يُفكَّك جزءًا جزءًا — **محليًّا بلا شبكة**
- **تحذير الأوامر الخطِرة**: `rm -rf` و `chmod 777` وأمثالها
- **قاموس مصطلحات محلي**: جواب فوري لأكثر من ٨٠ مصطلحًا أمنيًّا
- **دفتر المصطلحات**: تحفظ ما تعلّمته وتصدّره Markdown
- **لخّص المهمّة**: هدف الغرفة وخطواتها وأوامرها
- **ترجمة الصفحة**: طبقة عربية تحت كل فقرة، بلا لمس الكود ولا الطرفية

**الضمانة الأساسية:** الأوامر وعناوين IP والمسارات والأعلام **لا تُرسل لأي
نموذج إطلاقًا** — تُقنَّع قبل الإرسال وتُستعاد بعده حرفًا بحرف.
